# JS basics

## Grade "Good"
Create application "Weather":
- use [API](https://openweathermap.org/)
- field **"Search"** with an opportunity to enter city
- button **"Get the weather"** onClick={show info about current weather in the city}
- minimum 5 weather features
- while loading show **loader** (load animation)


## Grade "Excellent"
All conditions from ["Good"](##-grade-good) and:
- five day forecast
- last found cities history through `localStorage`
- button **Update** onClick={update weather data}
- after 5 minutes sicne the last weather receiving show info that the weather changed
