# Lab №3

## Task

**Modularity and handling all cases**

**Deadline:** 1 week from lecture 26.09

## Grades

### "Satisfactory"
- Improve your todo-list.
- Connect [json-placeholder](https://jsonplaceholder.typicode.com/) API.
- Get the todo list from there.
- Split the code into modules.
- Alternative: use another public todo list API or raise your own `json-server`.

### "Good"
All conditions from ["Satisfactory"](##-grade-satisfactory) and:
- In the weather app:
  - Split the code into modules.
  - Implement a `debounce` function and use it in the app.
  - Library is not allowed.
  - Implement caching (session only).

### "Excellent"
All conditions from ["Good"](##-grade-good) and:
- Implement separate behavior for request errors:
  - no network
  - nothing found
  - something went wrong (anything else)
- Output the received error code on the error screen.
